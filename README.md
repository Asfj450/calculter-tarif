# رِبح — حاسبة الاستيراد المصغّر

واجهة عربية لحساب تكلفة المنتجات ومصاريف الرحلة والجمارك وسعر البيع والربح المتوقع. تدعم العملات والتوزيع حسب القيمة أو العدد أو الوزن، مع تصدير البيانات وحفظها محليًا في المتصفح.

## التشغيل المحلي

```sh
python3 -m http.server 8765 --directory docs
```

## GitHub Pages

من Settings → Pages اختر Deploy from a branch، ثم main والمجلد /docs واضغط Save. الموقع ثابت ولا يحتاج قاعدة بيانات أو مفاتيح سرية.

## الاختبارات

```sh
node --test calc.test.mjs input.test.mjs
```

## الحساب والخصوصية

القيمة الجمركية مستقلة عن تكلفة الشراء الفعلية. الإعداد المرجعي: حقوق 5% وIFU بقيمة (القيمة الجمركية + الحقوق) × 1.30 × 0.005. حصة المصاريف المشتركة تضاف للمنتج ثم تقسم على القطع القابلة للبيع. هامش الربح يُحسب من سعر البيع. أسعار الصرف والرسوم غير المؤكدة تُدخل يدويًا.

البيانات الشخصية للرحلات لا تُرفع إلى GitHub؛ تُحفظ في localStorage. الانتقال من النسخة المحلية إلى الموقع المنشور يحتاج تصدير JSON ثم استيراده هناك.

المراجع داخل صفحة دليل البداية؛ آخر مراجعة 11 نوفمبر 2026. هذه أداة تقدير، والقيمة النهائية تعتمدها الجمارك.
